## AI 查询 API 改为「双源合并 + 推荐」

- 需求：一次请求同时查 local 索引与 Danbooru Tag Searcher，把两边结果拼在一起返回；并像站点「搜索标签」一样带上推荐画师 / 同类标签 / 相关标签，方便 AI 一次拿到完整信息。
- 契约（`app/lib/ai-tag-search.ts`）：
  - `source` 由 `local|danbooru` 改为 **`all`(默认)|local|danbooru**；新增 `recommend`（0/1，默认 1）。
  - `limit` 语义改为**按源**：本地最多 limit 条 + Danbooru 最多 limit 条；`offset` 只对本地分页，`source=danbooru` 仍要求 0。
  - 每条结果新增 `source: local|danbooru`；响应新增 `counts {local,danbooru}`、`unavailable: ("danbooru"|"recommendations")[]`、`recommendations`。
  - 合并规则：本地命中在前（exact→alias→prefix→contains），Danbooru 语义命中在后（match=semantic），按 tag 归一化去重且本地优先。
  - **降级**：`all` 模式下 Danbooru 失败不报错，只返回本地结果并记入 `unavailable`；只有显式 `source=danbooru` 才 503。
- 推荐（`lib/ai-tag-recommendations.ts` 新增 + `app/lib/danbooru-types` 复用）：
  - 依据 = 合并结果里最靠前的标签（`recommendationTags()`，剥离 `artist:` 前缀、最多 8 个）；分类 = Danbooru 结果里合法的那 5 个分类。
  - 返回 `artists`（画师 + cooc_count/post_count/top_tags）、`sameCategory`、`related`；`recommendations=null` 表示未执行（`recommend=0` 或 `source=local`）。
  - 尽力而为：失败/限流 → 三个数组为空 + `unavailable: ["recommendations"]`；成功缓存 1 天、2 并发、20 次/分。
- `lib/danbooru-recommendation-service.ts` 重构：抽出可复用的 `fetchDanbooruRecommendations(input, signal, { quota })`，`quota: "public"` 时**不发送站点注册头、无 Key 时匿名回退国际节点**（与 `searchDanbooru` 一致）；`categories` 为空时 `sameCategory=[]` 且 `related` 承载全部，避免两个桶重复同一批数据（站点路径必传分类，行为不变）。
- MCP：新增 `search_all_tags`（合并 + 推荐 + 例图，推荐首选），`search_danbooru_tags` 加 `recommend`，`search_tags` 保持纯本地零额度。
- 文档：llm.md/llm.txt 重写为「双源合并搜索」「推荐」「内联例图」三节并附完整示例响应；OpenAPI version → 1.2.0（后被并发会话改为 1.3.0）并补齐新字段；README AI 段与 MCP 段重写。
